# WSGI server with real HTTP keep-alive + built-in TLS (BuiltinSSLAdapter, stdlib ssl) -- replaces the
# werkzeug dev server so an HTTPS poll reuses one TLS session instead of paying a fresh handshake each
# time. Pure-Python (more-itertools + jaraco.functools); NO compiler needed. Do NOT add the [pyopenssl]
# extra (it would pull cryptography/cffi). On Raspberry Pi OS install via apt (python3-cheroot, 10.x) --
# the system Python has no pip; the >=10 floor accepts what apt ships. setup.sh installs it. (If cheroot
# is missing at runtime the app falls back to the werkzeug server, minus keep-alive.)
cheroot>=10,<12
# Web Push notifications (optional at runtime -- the app degrades gracefully if these are

# py-vapid signs the VAPID JWT, http-ece does the RFC 8188 aes128gcm payload encryption, and
# requests makes the HTTPS POST. On Raspberry Pi OS install via apt (python3-py-vapid,
# python3-http-ece, python3-requests -- these pull cryptography as python3-cryptography, no
# source build). See the wiki "Web Push Notifications" page.
py-vapid
http-ece
requests
